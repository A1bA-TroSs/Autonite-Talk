# Autunite handoff

Planning and visual reference package for Claude Code. **Autunite is a provisional name.** The product concept and revised logo form were confirmed in conversation; the name, UI styling, technical architecture, and thresholds remain proposals until tested or approved.

## Start here

1. Read [INTENTIONAL.md](INTENTIONAL.md) for product intent, behavior, scope, and verification gates.
2. Read [IMPLEMENTATION_BLUEPRINT.md](IMPLEMENTATION_BLUEPRINT.md) for every screen, setting, meter state, report record, data boundary, and acceptance check.
3. Read [DESIGN.md](DESIGN.md) for UI structure, visual rules, copy, and asset usage.
4. Use [CLAUDE_CODE_HANDOFF.md](CLAUDE_CODE_HANDOFF.md) as the first prompt or task brief in Claude Code.
